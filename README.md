# 블로그 스튜디오

장소 정보, 사진, 방문 메모를 입력해 네이버 블로그 게시용 원고를 작성하는 로컬 웹 앱입니다. React, TypeScript, Vite, styled-components, Express, SQLite와 Prisma, TipTap, Lucide React, dnd-kit을 사용합니다.

## 설치와 실행

Node.js 20.19 이상이 필요합니다. 처음 실행하거나 Prisma 스키마가 변경되면 DB를 준비합니다.

```sh
npm ci
cp .env.example .env
npm run db:setup
npm run dev
```

개발 화면은 http://127.0.0.1:5173 에서 열립니다. 빌드 후에는 `npm run build`와 `npm start`를 실행하고 http://127.0.0.1:4174 에 접속하세요. 기존 `.env`가 있다면 복사 단계는 건너뜁니다.

## API 연결

프로젝트의 `.env`에서 값을 설정하고 서버를 재시작합니다. 설정 화면에는 환경변수 등록 여부와 모델 이름만 표시됩니다.

| 환경변수 | 용도 |
| --- | --- |
| `OPENAI_API_KEY` | 사진과 메뉴판 분석, 글 생성 및 교정, 스타일 분석 |
| `OPENAI_MODEL` | 이미지 입력과 JSON 출력을 지원하는 모델. 기본값은 `gpt-4.1-mini` |
| `GOOGLE_PLACES_API_KEY` | 장소 검색. Google Cloud에서 Places API (New)와 결제를 활성화 |
| `DATABASE_URL` | SQLite 파일 위치. 기본값은 `prisma/studio.db` |
| `PORT` | Express 로컬 포트. 기본값은 4174 |
| `UPLOAD_DIR` | 선택 사항. 기본 사진 보관 폴더는 `uploads/` |

키가 없어도 수동 입력, 업로드, 편집, 저장, 복원, 미리보기와 복사를 사용할 수 있습니다. AI를 실행하면 작성 입력과 분석에 필요한 사진 또는 스타일 예시가 OpenAI로 전송됩니다. 장소 검색에는 입력한 검색어가 Google로 전송됩니다. 사업장 자료를 사용할 때는 공급자 약관과 정보 출처를 확인하세요.

## 사용 흐름

1. 장소 이름과 지역을 입력합니다. 장소 검색에서 후보가 여럿이면 방문한 지점을 선택합니다. 직접 작성하려면 **직접 입력**을 누릅니다. 영업시간 또는 휴무일을 직접 입력할 때는 출처와 확인 날짜도 기록합니다.
2. JPG, JPEG, PNG, WEBP 사진을 최대 30장까지 추가합니다. 사진 크기는 장당 12MB까지입니다. HEIC는 JPEG 변환 후 추가하세요. 사진은 드래그하거나 위아래 버튼으로 순서를 바꿉니다.
3. 사진 카테고리와 메모를 입력하고 **사진 AI 분석**으로 관찰 내용과 메뉴판 정보를 확인합니다. 초안을 생성할 때 아직 분석하지 않은 사진은 자동으로 분석합니다. 불확실한 메뉴는 **확인 필요**를 유지하거나 원문을 확인한 뒤 수정합니다.
4. 방문 메모와 글쓰기 설정을 입력하고 AI 초안을 생성합니다. 실제 주문과 메뉴판 전체 목록은 별도로 작성합니다. 장소 위치와 영업정보는 방문 경험과 별도로 저장됩니다.
5. **편집**에서 제목, 본문, 사진 설명과 태그를 바꿀 수 있습니다. 문단 재작성은 커서가 있는 문단으로 한정됩니다. 맞춤법 확인과 전체 재작성은 제안을 확인하고 적용합니다. 포스팅 수정 내용은 잠시 후 자동 저장되며 각 저장 시점은 수정 이력에서 복원할 수 있습니다.
6. **내 블로그 스타일 분석**에서 공개 네이버 RSS의 텍스트를 가져오거나 글을 직접 붙여넣고 UTF-8 TXT 또는 Markdown 파일을 첨부합니다. 서로 다른 글 10개 이상을 권장합니다. RSS 본문이 축약된 경우 원문을 직접 추가하세요. 분석 결과와 글쓰기 기본값은 편집 후 저장할 수 있습니다. 편집한 문체를 학습 규칙에 반영하려면 포스팅 편집 화면에서 승인합니다.
7. PC·모바일 미리보기로 원고를 확인합니다. 제목, 본문, 태그를 복사하고 사진은 원고에 표시된 순서대로 직접 첨부합니다. HTML에는 사진 파일이 포함됩니다. Markdown으로도 내보낼 수 있습니다. Markdown 사진 링크는 로컬 서버 주소를 가리킵니다. 네이버 게시 작업은 사용자 계정의 편집기에서 직접 진행합니다.

## 데이터와 검사

이 앱은 루프백 주소에서 실행하는 1인용 도구입니다. 백업할 때 앱을 종료하고 SQLite DB와 사진 폴더를 함께 복사합니다. 현재 원고에서 사진을 제거해도 이전 버전에서 복원할 수 있도록 파일을 보관합니다.

```sh
npm run typecheck
npm run build
npm test
```

기본 테스트는 임시 SQLite DB와 로컬 HTTP 서버에서 사진 업로드, 포스팅 저장, 버전 복원, 저장 충돌, API 미설정 상태를 확인합니다. 실제 외부 API 호출에는 각 서비스 키가 필요합니다.
